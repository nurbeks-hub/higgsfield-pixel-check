# Пиксельная сверка генераторов

26 фотогенераторов Higgsfield, один промпт, по два дубля на максимальных настройках (21:9, где нет — 16:9).
Страница: https://nurbeks-hub.github.io/higgsfield-pixel-check/

Оценивается структура пикселей (реальное разрешение, сетка декодера, алиасинг, шум, пересвет, сцепка цветовых каналов), а не композиция.
Скрипты анализа — в `tools/` (numpy + Pillow).
